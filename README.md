# Jornada do Java ao Python

Repositório com os códigos e exercícios desenvolvidos durante meus estudos de Python na playlist **Jornada do Java ao Python**, do canal [@giulianabezerra](https://www.youtube.com/playlist?list=PLAI-Jt0jFgxQ).

O material acompanha a sequência das vídeos: começa pelos fundamentos da linguagem e avança até recursos modernos e conceitos de orientação a objetos. Também inclui pequenos projetos práticos feitos ao longo do aprendizado.

## Conteúdo

| Arquivo | Assuntos |
| --- | --- |
| `1_fundamentos_python.py` | Primeiro programa, sintaxe, tipos, variáveis, operadores e condicionais |
| `2_funcoes_containers.py` | Funções, parâmetros, escopo, exceções e containers (listas, tuplas, dicionários e conjuntos) |
| `3_strings_loops.py` | Strings, formatação, laços `for` e `while` e exercícios |
| `4_modulos_arquivos.py` | Módulos, leitura e escrita de arquivos e arquivos CSV |
| `5_paradigmas_filosofia_python.py` | Paradigmas e conceitos iniciais de orientação a objetos |
| `6_four_pilars_oop_python.py` | Encapsulamento, abstração, polimorfismo, herança e composição |
| `7_oop_pratica_python.py` | Prática de orientação a objetos e projeto de cartas/jogo |
| `8_python_moderno.py` | Type hints, dataclasses, duck typing, protocols e estilo Pythonic |
| `hangman.py` | Jogo da forca interativo no terminal |
| `biblioteca.py` | Exemplo de sistema de biblioteca com livros, usuários e empréstimos |
| `modules/` | Exemplos de criação e importação de módulos próprios |
| `*.txt` e `*.csv` | Arquivos de apoio para os exemplos de entrada, saída e manipulação de dados |

Os arquivos numerados funcionam como caderno de estudos: reúnem exemplos e desafios comentados. Os scripts que solicitam dados pelo terminal são interativos.

## Requisitos

- Python 3.10 ou superior (o arquivo `8_python_moderno.py` usa sintaxe de tipos introduzida no Python 3.10).
- Não há dependências externas; os exemplos usam a biblioteca padrão do Python.

## Como executar

Clone o repositório, entre na pasta e execute o arquivo desejado com Python:

```bash
python3 1_fundamentos_python.py
```

Por exemplo, para iniciar o jogo da forca:

```bash
python3 hangman.py
```

Alguns arquivos são coleções de demonstrações e exercícios; leia o código e descomente ou adapte os trechos conforme indicado para experimentar cada exemplo. Execute a partir da raiz do projeto quando o exemplo acessar arquivos de apoio, como `movies.csv` ou arquivos de texto.
